❓ Questions fréquentes
Comment passer une commande ? +
Choisissez vos produits → Ajoutez au panier → Passez la commande → Remplissez vos infos → Choisissez le mode de paiement → Envoyez le paiement au numéro indiqué.
Quels sont les délais de livraison ? +
Les délais varient selon les produits. Le délai est indiqué sur chaque commande. Nous vous informons à chaque étape de votre commande.
Comment payer ? +
Nous acceptons Wave, Orange Money et Moov Money. Après votre commande, les instructions de paiement vous sont affichées directement dans l'application.
Ma commande est-elle sécurisée ? +
Oui ! Toutes vos données sont sécurisées. Votre paiement n'est effectué qu'après confirmation de votre commande par notre équipe.
